## Sobre

Landing page tematica de God of War Ragnarok, focada em composicao visual, SCSS e responsividade.

O objetivo deste repositorio e demonstrar uma implementacao clara, organizada e facil de avaliar, com documentacao objetiva para recrutadores e pessoas tecnicas entenderem rapidamente o contexto do projeto.

## Funcionalidades

- Hero visual.
- Secoes de personagens.
- Assets otimizados.
- Estilizacao com SCSS.
- Layout responsivo.

## Stack

- **HTML**
- **SCSS**
- **JavaScript**
- **CSS**

## Como executar

```bash
git clone https://github.com/marquesmaycon/god-of-war-ragnarok.git
cd god-of-war-ragnarok
npm install
npm run dev
```
